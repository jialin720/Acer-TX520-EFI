## 适用场景

- 核显：UHD 620 或 UHD 630
- 屏幕接口：LVDS（老机器常见）或 eDP
- 症状：开机闪 Logo、进系统后间歇性横纹抖动、睡眠唤醒后闪烁、浅色背景时忽明忽暗

**如果你的情况符合上面任意一条，这个方案大概率能帮到你。**

## 核心操作

就两步，五分钟的事。

### 第一步：添加显卡属性

在 `config.plist` 的 `DeviceProperties` 中，找到核显的设备路径（通常是 `PciRoot(0x0)/Pci(0x2,0x0)`），加入以下内容：

```xml
<key>framebuffer-con0-flags</key>
<data>hwEAAA==</data>
如果试了没效果，把 con0 依次换成 con1 或 con2 再试。不同主板的屏幕输出通道索引不一样，这个要靠自己试，没办法一步到位。

第二步：添加启动参数
在 boot-args 中追加：

text
-igfxcdc igfxonln=1
保存、重启。没了，就这两步。

原理说明
（这一部分写给愿意了解背后逻辑的人，不感兴趣可以直接跳过。）

framebuffer-conX-flags 这个值对应的是 Intel 显卡驱动中的一组电源管理标志位。0x00000187 这个数值的作用是强制锁定屏幕接口通道的供电状态，不让 macOS 的电源管理机制在空闲时对屏幕供电做动态调整。

绝大多数闪屏问题的根源，其实是 macOS 对某些非标准屏幕的电压调节策略过于激进，导致屏幕在低负载状态下供电不足、出现抖动。-igfxcdc 和 igfxonln=1 则进一步禁用了时钟动态调整功能，让显示管线始终保持在活跃状态。

这套方法的优势在于，它绕过了 EDID、通道数、BusID 这些变量，直接作用于 GPU 的电源管理单元。所以它不挑机型，只要核显架构相同、屏幕接口类型相同，就能用。
